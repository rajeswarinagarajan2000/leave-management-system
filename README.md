# Leave Management System

An end-to-end leave request and approval app on the Microsoft Power Platform.

> Self-initiated portfolio project by **Rajeswari Nagarajan** · Jul – Oct 2026 · Sample data only.

**Screenshots and demo:** [Portfolio → Leave Management System](https://rajeswarinagarajan2000.github.io/#p-leave)

## What it does

- Separate role-based screens for **employees** and **managers**.
- Employees submit **Casual, Earned or Permission** leave. Total days are calculated automatically.
- A **Power Automate** flow emails the manager as soon as a request is created.
- The manager **approves or rejects** in one click, and the status updates in the app.
- A **dashboard** shows totals and colour-coded status history.

## Built with

Power Apps (canvas) · Power Fx · Power Automate · SharePoint Lists · Outlook

## Files

- App export package (`.zip`) and flow export, uploaded to this repo.

## How to rebuild

1. Create the SharePoint lists on any site.
2. In [make.powerapps.com](https://make.powerapps.com): **Apps → Import canvas app** → choose the package.
3. Point the data sources to your SharePoint lists.
4. Import the flow, connect Outlook and SharePoint, and turn it on.
